# План · ядро ~год + фаза 2

Актуально: **ноябрь 2026**. Публичный трек middle / middle+ Python backend
и одновременно **личная система ремесла**.

**Приоритеты (выше → ниже):**

1. радость ремесла — руками понимаемый код, без потока «непонятной генерации»;
2. научиться думать (алгоритмически и абстрактно; SICP и научный стиль — фон
   и фаза 2, не декорация);
3. уверенный middle на любом рынке (не только РФ);
4. возможность уехать — следствие навыков и английского техразбора, не отдельный
   «курс эмиграции».

Попытка в крупную компанию / Яндекс — **вторичный гейт**, не смысл учёбы.

**Ядро:** ориентир **9–12 месяцев** при 10–12 ч/нед (~40–50 рабочих недель).
Календарь уступает качеству слоёв. **Фаза 2** — открытый трек после ядра
(полный SICP, глубже OS/сети/Postgres internals, полный SD).

Скелет старого интенсива ~5 недель — только [калибровка темпа](../reference/legacy-5w.md).

Педагогика слоёв — Berkeley 61A → 61B → 61C и MIT (язык → алгоритмы → машина →
системы → дизайн), плюс явный навык **читать чужой код** и короткий слой
**сетей** до FastAPI.

## 2. Цель и гейты

**Цель ядра:** уметь самому разобрать незнакомую задачу циклом; написать и
протестировать понятный код; прочитать чужой фрагмент и назвать инвариант и
края; объяснить async, SQL и устройство сервиса; получать удовольствие от
работы руками. Собес middle — проверка, не единственный KPI.

**Срезы-моки** (по материалу, **не** задачи из Harbor):

| После пакета | Формат |
|--------------|--------|
| M0.5–M1 | голос Python + короткий applied/typing |
| M2–M3 | алго 60–80 мин (с циклом; часть голоса на EN) |
| M4–M5 | concurrency устно + async pytest на чужом каркасе |
| M6–M7 | SQL/API устно + applied 90–120 мин |
| M7–M8 | короткий устный **system design** (карточки) |
| M8–M9 | сервис + compose / поиск устно |
| M10–M11 | mixed + опционально Go |

Полигон длинной практики стека — [Harbor](./capstone-harbor.md).
Моки с ним не смешиваем: [mocks](../mocks/index.md).

Архив мышления на рабочей задаче (закрыт): приватный репо
`postgres-rest-api-service` — пример цикла на Flask+psycopg2, не второй capstone.

## 2a. Сквозной проект · Harbor

Один продукт на весь горизонт: **бронирование переговорок**, async API,

## 3. Принцип наслоения

```text
Как решать задачу (цикл; в т.ч. вне кода)
        ↓
Абстракции Python (+ M1b: исключения, генераторы, пакеты, Pyright)
        ↓
Алгоритмы + структуры (Skiena рабочий; CLRS справка; + аллокатор Harbor)
        ↓
ОС-каркас (OSTEP + CSAPP-lite; Linux сейчас; BSD/OpenBSD — фон)
        ↓
Сеть на пальцах (Kurose/сокет → TCP → HTTP) → threads → asyncio
        ↓
Тесты + рефакторинг + чтение чужого/legacy кода
        ↓
Данные: Postgres → DDIA-мост → (NoSQL/Elastic)
        ↓
HTTP API + Docker  (+ карточки system design)
        ↓
K8s карточки · Go-воркер
        ↓
Гейт (по желанию) → Фаза 2 (SICP, глубже сети/OS/SD)
```

Фоном всю дорогу: git (аварии), ОС/терминал через
[exploring-os-ru](https://github.com/SillyHatsOnly/exploring-os-ru) выборочно,
микрозадачи с циклом, срезы-моки, Harbor, SD-карточки,
английский **техразбор** 10–15 мин после русского цикла (с M2).

## 7. Антицели привычек

- Не начинать слот с «сгенерируй мне решение». Сначала цикл и свои руки;
  модель — после своего brute или для ревью краёв.
- Каркас (инициализация репо, бойлерplate конфига) можно автоматизировать;
  **наполнение и инварианты** — своими руками.
- Один пропущенный день ≠ срыв системы: следующий слот по расписанию.

## 9. Критерий «ядро прожито» (не только собес)

- [ ] Цикл на алго и на applied без пустой тишины (выход L0)
- [ ] Чужой фрагмент: инвариант + края + что сломал бы (L1)
- [ ] Python M1b закрыт без «дыр» yakimka P0 по ядру
- [ ] Алго: brute → приём → код; Big O своим голосом (L2; Skiena-навык)
- [ ] Async + ОС-голос: process / thread / FD / blocking I/O (L3–L4)
- [ ] Сеть: сокет → TCP → HTTP одной картинкой вслух (L4)
- [ ] Тесты: зелёный рефакторинг или тест ловит названный баг (L5)
- [ ] Postgres: индекс, EXPLAIN, txn, lost update, ACID vs BASE (L6)
- [ ] DDIA-идеи: репликация/партиционирование «зачем и чем платим» (L6–L7)
- [ ] Harbor: модели → allocate → тесты → API → compose
- [ ] Базовый SD: 4–6 коробок + bottleneck
- [ ] Техразбор решения на EN ~10–15 мин
- [ ] Радость: можешь объяснить свой код без стыда за «я это сгенерил и не понял»

После ядра — фаза 2 без обрезки удовольствия.
