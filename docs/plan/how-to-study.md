# Как учиться

## Правило нуля

Всё, что связано с **вашим** кодом (Harbor, drills, линтеры, Docker, CI):

1. сначала «зачем»;
2. вы сами вводите команды и создаёте файлы;
3. агент не коммитит каркас за вас «чтобы сэкономить время».

Сайт курса — готовый учебник. Локальный просмотр — ваши команды.

Канон: [DOC_GENERATION §0](../canon/DOC_GENERATION.md).

## Цикл мышления (всегда)

Любая задача (алго, applied, рабочая, даже бытовая неопределённость) идёт
через [цикл](../modules/m0b-thinking/index.md):

1. уточнить условие и края;
2. свои примеры (вход → выход);
3. brute force;
4. оценка сложности / узкое место;
5. упростить / узнать паттерн;
6. сухой прогон (псевдокод на бумаге);
7. код;
8. рефакторинг без смены алгоритма;
9. edges + тесты;
10. рефлексия.

На собесе тишина хуже медленного рассуждения вслух.

Вне кода тот же порядок: уточнить → примеры исходов → самый тупой рабочий
план → где узкое место → упростить → проверить на краях.

## Нейросеть: где да, где нет

Долгие компетенции (инструменты сменятся, навык нет):

1. сформулировать задачу *до* генерации;
2. дать контекст (инвариант, края, существующий код);
3. критически прочитать ответ модели;
4. проверить тестом;
5. объяснить принятое вслух;
6. уметь выкинуть и переписать руками.

Правила слота:

- **Нельзя** начинать с «напиши мне решение». Сначала цикл и свои руки.
- **Можно** после своего brute: края, которые не назвали; разбор чужого
  фрагмента; объяснение ошибки теста.
- **Можно** автоматизировать рутину каркаса (venv, gitignore), если понимаете
  каждую строку. Наполнение инвариантов — ваше.
- Если «вставил и не могу пересказать» — удалить и написать заново. Это цель
  курса, не потеря времени.

## Дисциплина старта

Слот в календаре — встреча, не настроение. Пол слота: **25 минут** с
открытым следующим шагом (записан в конце прошлого занятия). Телефон не на
столе. Один пропущенный день ≠ срыв: следующий слот по расписанию.

## Утренний блок (пн / ср / пт)

1. **15 мин** — голос вслух по вчерашнему (с циклом).
2. **Теория** — глава модуля.
3. **Практика руками** — drills / слой Harbor.
4. С M2: **10–15 мин** техразбор того же решения **на английском** (простые
   слова, без остановки на словаре).
5. **2–3 мин** — вопросы к ревью + одна строка «следующий шаг».

## Микрозадачи на работе

Карточка голоса **или** одна easy через цикл. Таймер 10–15 мин.
Без «сгенерируй easy за меня».

## Ревью

«ревью M0.5» / «ревью M1» / «ревью M2» + ваши файлы. Эталон — после ревью,
часто под катом на странице домашки.

## Книги и выходы слоёв

Полка без зачёта «прочитал» — декорация. Смотри
[канон источников](../reference/sources-canon.md) (тиры + бинарный выход слоя)
и [каталог ID](../reference/books.md).

Коротко по ходу ядра:

- M2–M3: **Skiena** как рабочий голос выбора алгоритма; CLRS — справка;
- M4a: **OSTEP** (+ CSAPP/Petzold по отсылкам главы);
- M1b/M5: Ousterhout + Feathers (сложность и чужой код);
- M5: Khorikov + Refactoring;
- конец M6 → SD: **DDIA** (лучше 2e);
- фон: *Pragmatic Programmer*, Pro Git, Швец 8–12, SICP ≤1 гл./мес.

Не копим 18 «essential» книг параллельно с модулем — одна опора слоя.
