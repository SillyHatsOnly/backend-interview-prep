# Эталоны решений

Сюда попадают разборы **только после** того, как задание сдано и разобрано
в ревью (чат). Заранее эталоны не публикуем — чтобы не было соблазна
подглядывать и копипастить.

## Правила

1. Пока домашка пакета открыта — в `solutions/` пусто или только этот README.
2. После ревью — короткий эталон / заметки: `solutions/mN-hwK.md` (или код).
3. В эталоне: идея, края, типичные ошибки; не «единственно верный» копипаст
   на все случаи.
4. PDF книг сюда не кладём.
