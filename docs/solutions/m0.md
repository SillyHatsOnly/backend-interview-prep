# Эталон · M0 · Старт

После ревью в чате (закрыт). Не подглядывать **до** своей сдачи M0.

## Что считается сдачей

| Пункт | Критерий |
|-------|----------|
| Текст | 8–10 предложений: зачем гейт ~6–8 мес; что реально тревожит в процессе |
| Drills | свой venv, `add` + pytest green, ≥2 коммита, свой `git log` |
| Голос | наслоение плана ≤60 сек своими словами |
| Harbor | свой venv в продукте, smoke (`health` или аналог) + pytest + коммит; не готовый scaffold |
| STAR | hard / позже — не блокер закрытия M0 |

## Текст · идея ответа

Хороший текст отвечает на два вопроса: **зачем** (грейды, фундамент, рынок)
и **что пугает** честно. Страх «объёма Postgres» и страх «лени / срыва дня»
оба валидны — важна стратегия восстановления.

### Принятый пример (рефлексия после ревью)

Хочу сменить работу: на текущей позиции уже несколько лет, роста давно нет,
уровень ощущается как junior / junior+. Нужны фундаментальные знания
(программирование, CS, сети, ОС) и привычка решать сложные задачи с минимумом
нейросетей — чтобы мозг не ленился. Цель — поднять грейд и найти место, где
навыки растут дальше; меньше бояться сокращения и «потом не найду работу».

Первый ориентир — порядка полугода до гейта, но учёба после выстраивания
привычки длится всегда дольше. В каждый момент есть сильные и слабые стороны;
их лучше подтягивать пластом (как с отстающим бицепсом: качаешь всё тело,
отстающее догоняет, развитие не однобокое).

Пугают не темы плана сами по себе, а лень и срывы выполнения. Один
пропущенный день ≠ срыв всей системы: пропустил — на следующем куске по
расписанию делаешь то, что должен. Это нормально. В остальном хочется расти;
дальняя личная цель — пройти SICP самостоятельно (в том числе на Scheme).

## Drills · края и ошибки

- `which python` / `which pytest` должны указывать в `drills/.venv/...`, не в систему.
- Drills — **отдельный** `git init`, не коммиты в репо учебника.
- Каталог `drills/` в учебнике лучше в `.gitignore` (песочница ≠ материалы курса).

## Harbor · края и ошибки

- Рабочее дерево после reset может быть почти пустым (README) — это старт.
- Старые коммиты scaffold в `git log` не использовать как учебный путь.
- Smoke (`health() -> "harbor-ok"`) проверяет цепочку продукта, не домен брони.
- Pyright и пакетная структура — позже (M1), не обязательны для закрытия M0.
- `git push` на origin — по желанию; для зачёта достаточно локального коммита.

## Голос · опора (не скрипт)

Мышление → Python-абстракции → алгоритмы → машина/ОС → concurrency → тесты →
Postgres → API → доставка; Harbor слоями; полгода–восемь месяцев — гейт, не потолок.
