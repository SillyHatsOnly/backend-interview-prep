# Моки · срезы знаний

Мок привязан к **пройденному материалу**, не к календарю и не к Harbor.
Harbor — длинная практика; на моке — **чужой** каркас / устные вопросы / алго.

Ориентир: после логически замкнутого пакета (M0.5–M1, M2–M3, M4–M5…) —
не обязательно «ровно 30 дней».

## Форматы

| Тип | Когда уместен |
|-----|----------------|
| Speak-aloud / мышление | после M0.5 |
| Алго 60–80 мин (с циклом) | после порции M2/M3 |
| Applied: чужой каркас + тесты 90–120 мин | после M1+M5 / перед API |
| Устный async / SQL / API | после M4 / M6 / M7 |
| Устный **system design** 20–30 мин | после M7–M8 ([карточки](../reference/sd-cards/index.md)) |
| Mini-сервис + compose | после M9 |

Примеры сценариев появятся как `checkpoint-01.md`, …

## Антицели

- Не «допиши Harbor» как единственный мок.
- Не мок ради галочки, если пакет ещё не закрыт.
- Не подменять SD-мок разбором только Harbor.
