# SD-01 · Сокращатель ссылок (naive → коробки)

**Когда:** конец M4 или после первого касания HTTP (M7).

## Условие (говорите вслух)

Сервис: длинный URL → короткий код; по короткому — редирект. Читают часто,
пишут реже. Старт: один регион, миллионы кликов/день — порядок, не точный SLA.

## Что ожидают

1. Требования: create, redirect; уникальность кода; что при коллизии.
2. Naive: таблица `code → url` в одной БД, один API-процесс.
3. Bottleneck: БД на каждый redirect; генерация кода; пик кликов.
4. Коробки: API · БД · (позже) кэш горячих кодов · (позже) LB.
5. Метрики: latency redirect, ошибка «не найден», hit rate кэша.

Не уходите в глобальный multi-DC и consistent hashing на первом заходе —
сначала naive и один явный bottleneck.
