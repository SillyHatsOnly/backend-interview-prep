# Книги · каталог отсылок

Файлы книг **не** в git. В материалах — нормальное **название, автор, издание**;
при чтении в главе — **глава / § / страница** + пересказ. Имена файлов на диске
и пути к домашней папке в курс не пишем.

Verbatim из книги — нельзя.

## Как ссылаться в главе

```text
Книга: Моргунов Е. П. — PostgreSQL. Профессиональный SQL, 2025.
Место: гл. … / § … / с. …
Дальше — пересказ своими словами.
```
