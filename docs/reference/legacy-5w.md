# Скелет · интенсив ~5 недель

Рядом с этим курсом локально может лежать архив короткого интенсива
(~5 недель), который использовали как **калибровку темпа**. В публичный git
текущего курса его не копируем.

Зачем хранить у себя:

- калибровка темпа / мотивации (блоки пн–ср–пт);
- уже плотные главы async/SQL — перенос идей в M4/M6, не слепое копирование;
- канон прозы перенесён сюда в адаптированном виде;
- EPUB больше не цель; публикация — этот сайт.

Что не переносить слепо:

- привязку к одной вакансии как единственную цель;
- чеклисты прогресса читателя;
- сборку epub как обязательный пайплайн.
