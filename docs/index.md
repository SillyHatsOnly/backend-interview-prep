# Backend Interview Prep

Курс на **~7.5–8 месяцев ядра** (+ открытая фаза 2) для middle / middle+
Python backend. Цель ядра — алгоритмическое мышление, coding, async, Postgres,
API и опыт; попытка в крупную компанию — **гейт**, не конец обучения.

Не про «выучить всё». Про **правильное наслоение**: абстракции → как решать
задачу → структуры → машина → concurrency → данные → сервис → доставка.

Начни с [плана](plan/PLAN_6M.md) и [как учиться](plan/how-to-study.md).

## Карта

1. **Старт + как решать задачу** — ритуал и цикл мышления (M0 / M0.5)
2. **Фундамент Python 3.10–3.13** — типы, dataclasses, декораторы (одна нить)
3. **Алгоритмы** — сложность → структуры → графы; всегда через цикл мышления
4. **Concurrency + ОС-каркас** — process/thread/FD → asyncio
5. **Тесты** — pytest, async pytest
6. **Postgres** — SQL → индексы → планы → транзакции
7. **HTTP / FastAPI** + **базовый system design** (карточки)
8. **NoSQL / Elastic** — вторично, с практикой
9. **Docker** · **K8s** карточки
10. **Go** — конец ядра
11. Фоном: **git**, **ОС** ([exploring-os-ru](https://github.com/SillyHatsOnly/exploring-os-ru)
    выборочно), микрозадачи, **срезы-моки**
12. Сквозь всё: capstone **[Harbor](plan/capstone-harbor.md)** — переговорки
13. После гейта: **фаза 2** — углубление без спешки
