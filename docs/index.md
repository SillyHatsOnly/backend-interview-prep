# Backend Interview Prep

Курс на **~9–12 месяцев ядра** (+ открытая фаза 2). Это и подготовка к middle
backend на Python, и личная система ремесла.

Приоритеты: **радость понятного кода руками** → умение думать (в т.ч. SICP
фоном) → middle на любом рынке → возможность уехать. Собес / Яндекс —
вторичный гейт, не смысл учёбы.

Наслоение: думать → Python → алгоритмы → машина и сеть → concurrency →
тесты → данные → сервис → доставка. Сквозь всё — Harbor и цикл мышления.

Начни с [плана](plan/PLAN_6M.md) и [как учиться](plan/how-to-study.md).

## Карта

1. **Старт + как решать задачу** — ритуал и цикл (M0 / M0.5)
2. **Python** — M1 + **M1b** (дыры ядра, Pyright, чтение чужого кода)
3. **Алгоритмы** — M2–M3; всегда через цикл; часть голоса на EN
4. **ОС + сеть + concurrency** — M4a / M4b
5. **Тесты** — pytest, async pytest
6. **Postgres** — SQL → индексы → планы → транзакции
7. **HTTP / FastAPI** + **базовый system design**
8. **NoSQL / Elastic** · **Docker** · **K8s** карточки · **Go**
9. Фоном: git, exploring-os-ru выборочно, SICP избр., паттерны
10. Capstone **[Harbor](plan/capstone-harbor.md)**
11. После ядра: **фаза 2**
