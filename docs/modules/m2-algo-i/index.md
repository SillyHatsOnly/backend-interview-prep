# M2 · Алгоритмы I

**Откуда:** [M0.5](../m0b-thinking/index.md) дал цикл, [M1](../m1-python/index.md)
дал комнату и запрос как объекты. Здесь те же задачи начинают стоить по-разному,
когда комнат и броней становится много.

**Сквозная нить:** подобрать переговорку. Сначала честно проходим все комнаты
(это уже умеет задание 6 из M1). Потом смотрим, где проход лишний: пара чисел
через множество, отсортированный ряд через два указателя или деление пополам,
вложенные скобки через стек, «отрезок подряд» через окно.

**Куда:** [M3](../m3-algo-ii/index.md) — этажи и крылья как граф, перебор
вариантов, очередь ожидания через кучу.

**Книги:** рабочий голос — Skiena *The Algorithm Design Manual*, 3e (`skiena`):
*какой* приём выбрать и почему. Старт чтения: гл. **1–2**; хеш — гл. **6**;
каталог Part II — когда задача «не знаю имя приёма». Справочник — CLRS 4e
(`clrs4`) по нужде. Карта: [reading-map · skiena](../../reference/reading-map.md).
Канон слоя: [sources-canon L2](../../reference/sources-canon.md).

**Выход пакета (грубо):** новая задача → brute → оценка → названный приём →
код; Big O своим голосом.

Каждая домашка начинается с цикла. Код без шагов 1–6 на ревью не засчитываем.
