# Чеклист · цикл на одну страницу

Держите рядом на алго и на applied.

```text
[ ] 1. Условие своими словами (вход / выход / ограничения)
[ ] 2. 2–3 своих примера, в т.ч. край
[ ] 3. Brute force вслух (верное, пусть медленное)
[ ] 4. Сложность brute; где узкое место
[ ] 5. Упрощение / паттерн / инвариант
[ ] 6. Код (или псевдокод → код)
[ ] 7. Edges прогнаны; одна фраза рефлексии
```

На собесе шаги 1–5 можно говорить без идеального кода. Не прыгайте к шагу 6.
