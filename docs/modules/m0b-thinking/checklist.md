# Чеклист · цикл на одну страницу

Держите рядом на алго и на applied.

```text
[ ] 1. Условие своими словами (вход / выход / ограничения)
[ ] 2. 2–3 своих примера, в т.ч. край
[ ] 3. Brute force вслух (верное, пусть медленное)
[ ] 4. Сложность brute; где узкое место
[ ] 5. Упрощение / паттерн / инвариант
[ ] 6. Сухой прогон: сложность улучшенного варианта и псевдокод на бумаге
[ ] 7. Код
[ ] 8. Рефакторинг (читаемость; алгоритм тот же)
[ ] 9. Edges прогнаны тестами
[ ] 10. Одна фраза рефлексии
```

На собесе шаги 1–6 можно говорить без идеального кода. К коду — после сухого
прогона. Рефакторинг — после кода, до тестов краёв (или сразу после green).
