# 01 · Граф площадки

**Мост:** список `MeetingRoom` из M1 — плоский каталог. В жизни у комнаты
есть сосед по коридору и родитель: крыло, этаж. Пока вы только ищете первую
вместимость, список достаточен. Как только вопрос «дойти от ресепшена до
крыла» или «все комнаты этого этажа», список без связей заставляет вас
каждый раз фильтровать все комнаты здания.

**Вопрос сюжета:** что хранить, чтобы «соседи этой площадки» были ответом
сразу, а не новым полным проходом?

### С собесов

«Что такое граф?», «чем дерево отличается?», «список смежности или матрица?».
Не просят теорию всех видов рёбер. Просят выбрать представление под задачу.

---

## Словарь

| Термин | English | На пальцах |
|--------|---------|------------|
| вершина | vertex | Площадка: здание, этаж, крыло, комната |
| ребро | edge | Связь «можно перейти» или «входит в» |
| список смежности | adjacency list | Для каждой вершины — список её соседей |
| дерево | tree | Граф без циклов, у каждой площадки кроме корня один родитель |
| цикл в графе | cycle | Можно ходить по рёбрам и вернуться, не повторяя ребро так, как задумали в задаче |

---

## Под капотом (модель)

Вершины — идентификаторы строк, не обязательно объекты со всей бронью.
Рёбра бывают двух смыслов, их не смешивают в одной задаче.

Иерархия «этаж содержит крыло»: ребро от родителя к детям. Это дерево, если
у крыла один этаж. Дети этажа читаются как список. Все комнаты этажа — обойти
детей и их детей, а не отфильтровать глобальный список по полю `floor`,
хотя для маленького Harbor фильтр честнее и проще. Граф окупается, когда
связей много и вопрос повторяется: «кто сосед».

Коридор «из крыла A есть дверь в крыло B»: ребро без родителя. У вершины
несколько соседей, циклы возможны (обошли этаж по кругу). Тогда список
смежности — словарь `id → список id соседей`. Матрица n×n на собесе
вспоминается, когда рёбер почти n². У здания так не бывает: у комнаты
два-три соседних входа, не связь со всеми. Список смежности меньше и
читается как план этажа.

Память списка смежности — число вершин плюс число рёбер. Поиск «есть ли
конкретное ребро» в списке соседей линейный по степени вершины. Если эта
проверка горячая, соседей кладут в множество. Это снова сделка памяти и
времени из M2, не новый закон.
