# 04 · Куча

**Мост:** несколько заявок ждут одну комнату. Каждый раз нужна заявка с
наибольшим приоритетом (или самая ранняя). Сортировать весь список заново
после каждой новой заявки дорого: O(n log n) на каждый приход. Куча держит
«кто сейчас первый» дешевле.

**Вопрос сюжета:** как забирать минимум (или максимум) много раз и не
сортировать очередь целиком?

### С собесов

«Что такое heap?», «сложность push и pop?», «чем не отсортированный массив?».
Реализацию просеивания на доске просят не всегда. Выбор структуры и цены —
да.

---

## Словарь

| Термин | English | На пальцах |
|--------|---------|------------|
| куча | heap | Дерево в массиве: у родителя значение не больше, чем у детей (мин-куча) |
| приоритетная очередь | priority queue | Абстракция «достань самый приоритетный»; куча — обычная реализация |
| push / pop | | Положить элемент / забрать вершину и восстановить порядок |

В Python это `heapq`: мин-куча на обычном списке. Максимум делают минусом
приоритета или кортежем, где первый элемент — то, по чему сравнивают.

---

## Под капотом (модель)

В мин-куче на вершине всегда самый маленький ключ. Это не отсортированный
массив: соседи по списку не стоят по возрастанию, гарантирован только
родитель и дети. Поэтому «второй по величине» не лежит в соседней ячейке.
Зато достать текущий минимум и починить дерево — O(log n). Положить новый
элемент — тоже O(log n). Посмотреть минимум, не забирая, — O(1).

Отсортированный список достаёт минимум за O(1) только с края, а вставка в
середину, чтобы порядок не сломать, — O(n) сдвиг. Когда заявки приходят
по одной весь день, куча выигрывает. Когда список уже полный и нужен один
раз порядок всех — обычная сортировка проще и честнее. Куча не «всегда
лучше sort».

Очередь ожидания Harbor: ключ — приоритет, при равенстве — время заявки.
`heappop` отдаёт, кого пускать следующим. Остальные в куче не сортированы
для печати «покажи всю очередь по порядку». Если продукт просит такой
экран, это отдельный проход, не свойство вершины.

Память O(n) на все ожидающие. Топ-k самых вместительных комнат без полной
сортировки — куча размера k: прошли список один раз, в куче держите только
k кандидатов. Время O(n log k). Для k, близкого к n, проще `sorted`.
