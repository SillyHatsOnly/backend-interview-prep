## Задание 1. Комнаты этажа *(обязательно)*

Дерево площадки задано словарём `children[id] = список дочерних id`. В этой
учебной модели любая вершина без детей считается комнатой. Даны словарь и
корень; верните листья под этим корнем в порядке выбранного обхода.

Вход:

```python
children = {
    "floor-1": ["wing-A", "wing-B"],
    "wing-A": ["A1", "A2"],
    "wing-B": ["B1"],
    "A1": [],
    "A2": [],
    "B1": [],
}
root = "floor-1"
```

Один допустимый выход для DFS слева направо:

```python
["A1", "A2", "B1"]
```

Сначала нарисуйте дерево и прогоните фронт рукой. Затем напишите, BFS это или
DFS, и почему для «просто собрать все листья» подходят оба, хотя порядок
может различаться.

**Края:** корень сам является листом; один уровень; у ветви нет комнат;
корня нет в словаре — выберите `[]` или ошибку и зафиксируйте контракт.

**Оценка:** O(V + E) для достижимой части дерева; объясните, почему у дерева
`E = V - 1`, если оно непустое и связное.

## Задание 2. Минимум коридоров *(обязательно)*

Неориентированный граф коридоров содержит цикл. Даны `start` и `target`.
Верните число рёбер кратчайшего пути или `-1`, если цели достичь нельзя.

Вход:

```python
graph = {
    "R": ["A", "B"],
    "A": ["R", "C"],
    "B": ["R", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"],
    "X": [],
}
```

Ожидаемые ответы:

```text
R → E: 3
C → C: 0
R → X: -1
```

В сухом прогоне показывайте очередь после каждого шага. Вершину отмечайте
посещённой при добавлении в очередь. Отдельно нарисуйте граф, где DFS первым
находит длинный путь, хотя короткий путь существует, и объясните, почему
стек не выполняет контракт минимума.

**Края:** старт равен цели; цели или старта нет; изолированная вершина;
цикл не зацикливает программу.

**Оценка:** O(V + E) времени и O(V) дополнительной памяти. Фраза «BFS —
O(n)» без определения `n` недостаточна.

## Задание 3. Точный набор комнат *(обязательно)*

Для учебной политики Harbor даны **положительные** вместимости комнат и
число `need >= 0`. Верните индексы разных комнат, сумма вместимостей которых
**ровно** равна `need`, или `None`.

Точное равенство здесь намеренно учебное. В реальном бронировании запас мест
обычно допустим, и тогда контракт и алгоритм надо выбрать заново.

Примеры:

```text
capacities=[4, 3, 2], need=6 → [0, 2]
capacities=[5, 3],    need=4 → None
capacities=[5, 3],    need=0 → []
```

Brute force словами — все подмножества. В коде нужен backtracking с одним
списком пути:

- индекс добавляется перед рекурсивным вызовом;
- после неуспешного вызова тот же индекс снимается через `pop`;
- готовый ответ отделяется от рабочего пути;
- один индекс нельзя использовать повторно.

Добавьте два доказуемых отсечения:

1. текущая сумма больше `need`;
2. текущая сумма плюс все оставшиеся вместимости меньше `need`.

Для второго отсечения заранее посчитайте суффиксные суммы. В тексте
объясните, почему первое правило верно только из-за положительных
вместимостей.

**Края:** `need == 0`; пустой список при ненулевой цели; одна комната даёт
ответ; общая сумма слишком мала; несколько допустимых ответов — вернуть
любой, но тест не должен требовать единственный порядок без такого контракта.

**Оценка:** худшее время O(2^n), рабочая память O(n). Не выдавайте pruning
за гарантию полиномиального времени.

## Задание 4. Очередь ожидания *(обязательно)*

Заявка — кортеж `(priority, arrived_at, request_id)`. Меньший `priority`
важнее; при равенстве раньше `arrived_at`; `request_id` уникален и служит
последним разрешением ничьей.

На `heapq` реализуйте две операции:

- добавить заявку;
- забрать следующую или вернуть `None`, если очередь пуста.

Последовательность для обязательного теста:

```text
push (2, 540, "req-B")
push (1, 550, "req-C")
push (1, 530, "req-A")
pop  → (1, 530, "req-A")
pop  → (1, 550, "req-C")
push (0, 560, "req-D")
pop  → (0, 560, "req-D")
```

Не вызывайте `sorted` внутри `pop` и не проверяйте внутренний список кучи
на полную сортировку. Тестируйте обещание последовательных извлечений.

Дополнительно одной фразой ответьте: какой ключ нужен для вопроса «какая
активная бронь закончится следующей?». Ожидаемая идея — время окончания
первым полем, например `(end_minute, room_id)`.

**Оценка:** `push` и непустой `pop` — O(log n), вершина — O(1), память —
O(n).

## Задание 5. Три разных «следующих» *(обязательно, текст)*

Напишите 10–14 предложений: чем отличаются

Для каждой структуры назовите, какой элемент она обязана отдать следующим и

Закончите правилом выбора структуры через операцию, а не через знакомое
название.

## Задание 6. Разбор чужого кода *(обязательно)*

Коллега хотел найти минимум коридоров:

```python
def distance(graph, start, target):
    frontier = [(start, 0)]
    visited = set()

    while frontier:
        vertex, steps = frontier.pop()
        if vertex == target:
            return steps
        visited.add(vertex)

        for neighbor in graph[vertex]:
            if neighbor not in visited:
                frontier.append((neighbor, steps + 1))

    return -1
```

Не запускайте код до первого ревью.

1. Оставьте комментарии минимум к трём проблемам. Среди них должны быть
   порядок `pop`, момент добавления в `visited` и поведение для отсутствующего
   `start`.
2. Постройте граф, где функция возвращает путь длиннее кратчайшего.
3. Исправьте функцию и прогоните очередь рукой на своём контрпримере.
4. Оцените исправленный вариант через `V` и `E`.

Задача проверяет не охоту за синтаксическими ошибками, а умение связать
контракт «минимум рёбер» с FIFO-порядком и моментом первого обнаружения.

## Задание 7. Hard · топ-k из потока

Комнаты приходят по одной как `(capacity, room_id)`. Храните только `k`
самых вместительных, не сортируя весь поток и не сохраняя все элементы.

Нужна куча размера не больше `k`, время O(n log k), память O(k). Продумайте
ничьи и края `k == 0`, `k > n`. Вернитесь после обязательных задач: здесь
легко перепутать, какой элемент должен лежать в корне ограниченной кучи.

## Когда пакет готов к ревью

- [ ] В графовой задаче не потеряны изолированные вершины.
- [ ] BFS отмечает вершину при добавлении и объясняет кратчайший путь только
  для одинаковой цены рёбер.
- [ ] Backtracking содержит симметричные выбор и откат; pruning доказан.
- [ ] Тест кучи проверяет порядок извлечений, а не вид внутреннего массива.
- [ ] Для каждого решения названы время и дополнительная память.
- [ ] Задание 6 содержит собственный контрпример и исправление.
