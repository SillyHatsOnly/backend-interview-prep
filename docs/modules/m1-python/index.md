# M1 · Python 3.10–3.13 · фундамент

**Откуда:** [M0.5](../m0b-thinking/index.md) дал цикл мышления. Здесь цикл
не бросаем: даже модель комнаты начинается с «что на входе / что ломается».

**Сквозная нить:** домен **переговорок**. К концу пакета умеете описать
комнату и запрос на бронь типами и dataclass, собрать объект из dict
(`classmethod`), обернуть вызов декоратором, прогнать **Pyright**. Логику
«какую комнату выбрать» пока не углубляем — это мост к M2.

**Куда:** M2 — сложность и структуры на том же домене (`allocate`, overlap).

**Книга (`typed-py`):** Алексей Голобурдин — *Типизированный Python для
профессиональной разработки* (ред. от 8 июня 2022). В главах — §/стр при
чтении. Каталог: [books](../../reference/books.md). Пересказ, не копипаст.

**Harbor:** модели в своём репо + проверка Pyright — руками, после «зачем».

## Мини-карта голоса пакета

> Dataclass — данные с авто `__init__`; frozen — DTO/ключ. classmethod —
> фабрика от класса; декоратор — обёртка с `wraps`. Типы — контракт для
> людей и Pyright, не runtime-магия.
