## Как перечитать M1 глубже

1. Перед кодом назовите инвариант `BookingRequest` и договор
   `MeetingRoom`.
2. Пройдите каждый сухой прогон на бумаге: конструктор, привязку метода,
   стек декораторов и вывод типа.
3. Выполните «Упражнение в главе» без интерпретатора, затем проверьте себя
   маленьким запуском.
4. После уже закрытых заданий 1–5 переходите к разделу
   «Углубление» в [домашке](./homework.md).

## Мини-карта голоса пакета

> Dataclass пишет механические методы, но инвариант формулируем мы.
> Frozen помогает сделать стабильный ключ только при хешируемых полях.
> classmethod — фабрика от фактического класса; небольшой API скрывает
> разбор данных. Декоратор — обёртка с `wraps`. Аннотации — контракт для
> людей и Pyright, а внешние данные всё равно валидируем в рантайме.
