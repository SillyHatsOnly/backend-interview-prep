# M0 · Старт и карта

Первый пакет: ритуал учёбы и **первые команды руками**. Никаких готовых
каркасов приложений «уже лежит в git» — Harbor и drills поднимаете сами
(агент объясняет зачем, вы печатаете).

### Зачем

Без ритуала полгода рассыпаются. M0 учит открыть учебник, завести песочницу
и понять, что репо продукта (Harbor) рождается с нуля, а не скачивается готовым.

## Цели

1. Прочитать [PLAN_6M](../../plan/PLAN_6M.md) и [как учиться](../../plan/how-to-study.md).
2. Поднять сайт курса локально (`mkdocs serve`) — сами.
3. С нуля: каталог drills + venv + pytest (агент ведёт по шагам в чате).
4. С нуля: репо Harbor — только после разбора «что такое проект / git remote /
   зачем README» (не клонировать «уже собранный каркас» как основу).
5. STAR-черновик локально.

## Сайт курса (учебник)

Репозиторий материалов уже есть — это книга, не ваш продукт:

```bash
git clone https://github.com/SillyHatsOnly/backend-interview-prep.git
cd backend-interview-prep
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-docs.txt
mkdocs serve
```

Онлайн (если Pages зелёный):
`https://sillyhatsonly.github.io/backend-interview-prep/`

## Harbor

Спека домена: [capstone-harbor.md](../../plan/capstone-harbor.md).

**Не** используйте заранее сгенерированный каркас как «уже готовое приложение».
В M0 в чате пройдёте: пустая папка → `git init` → зачем структура → что такое
зависимость / venv / тест / линтер (Pyright) — и только те файлы, которые
осознанно создадите.

## Ритуал утра

Теория → домашка руками → 2 минуты вопросов к ревью.

## Домашка M0

Ревью в чате: «ревью M0». Эталон в репо — только после ревью.

1. **Текст:** 8–10 предложений — зачем middle за 6 месяцев; что пугает в плане.
2. **Drills с нуля (в чате по шагам):** venv, функция `add`, pytest green,
   два коммита, `git log --oneline`.
3. **Голос:** наслоение PLAN_6M ≤60 сек вслух.
4. **Harbor:** старт с нуля под руководством в чате (не «скачал и уже pyright»).
5. **Hard / позже:** STAR локально.

## Мини-голос

> Учебник — сайт курса. Продукт — Harbor, с нуля. Инструменты (venv, pytest,
> pyright, git) вводятся с объяснением зачем, руками. Моки — срезы знаний,
> не задачи из Harbor.
